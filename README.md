A prototype music application that adapts msuic selection based on a user's heart rateand workout intensity.

## Feature
- Interactive BPM slider
- Music mood change baed on BPM
- Chill, Focued, Active, and workout modes
- Responsive interface built with HTML, CSS, and JavaScript

- CSS
- JavaScipt
