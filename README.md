# Pulse-Music-App
A prototype music application that adapts msuic selection based on a user's heart rate and workout intensity.

## Feature
- Interactive BPM slider
- Music mood change based on BPM
- Chill, Focused, Active, and workout modes
- Responsive interface built with HTML, CSS, and JavaScript

## Technologies
- HTML
- CSS
- JavaScipt

## Future Development
- Apple Music / Spotify integration
- Apple Watch / wearable heart rate integration
- Automatic msuic selection based on live heart rate
